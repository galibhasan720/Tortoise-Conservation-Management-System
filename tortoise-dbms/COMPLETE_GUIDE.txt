================================================================================
TROUBLESHOOTING GUIDE
================================================================================

PROBLEM: "Connection refused" or MySQL won't connect
SOLUTION: 
  1. Verify MySQL is running in XAMPP Control Panel (green indicator)
  2. Check port: Usually 3306
  3. Go to phpMyAdmin: http://localhost/phpmyadmin
  4. If you can access phpMyAdmin, MySQL is working


PROBLEM: "Table 'tortoise_conservation_db' doesn't exist"
SOLUTION:
  1. Go to http://localhost/phpmyadmin
  2. Re-import the database/fullDatabase.sql file
  3. Watch for any error messages during import
  4. Verify 11 tables appear in left sidebar


PROBLEM: "Access denied for user 'root'@'localhost'"
SOLUTION:
  1. Check XAMPP didn't set a MySQL password
  2. Edit db_connect.php and verify:
     $db_user = 'root';
     $db_pass = '';  // Empty!
  3. If you set a password, update both lines accordingly


PROBLEM: Page won't load / 404 error
SOLUTION:
  1. Verify Apache is running in XAMPP (green)
  2. Check file location: C:\xampp\htdocs\tortoise_management\
  3. Verify filename exactly matches in browser URL
  4. Files are case-sensitive in URL (index.php, not INDEX.php)


PROBLEM: Blank page / nothing displays
SOLUTION:
  1. Press F12 to open Developer Console
  2. Check for errors (should show in red)
  3. Look at server logs: C:\xampp\logs\php_error.log
  4. Refresh browser (Ctrl+F5 to clear cache)


PROBLEM: Database operations not working
SOLUTION:
  1. Verify db_connect.php can connect:
     - Uncomment: echo "Connected successfully";
     - Load http://localhost/tortoise_management/db_connect.php
     - Should display message
   2. If error displayed, database connectivity is broken
   3. Follow MySQL troubleshooting above
