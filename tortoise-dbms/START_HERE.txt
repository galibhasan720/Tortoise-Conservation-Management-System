🚀 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Install XAMPP (if not already installed)
─────────────────────────────────────────────────
Download: https://www.apachefriends.org/
Run installer with default options


STEP 2: Copy Project to XAMPP Directory
───────────────────────────────────────
Copy all files from: d:\New DBMS\Tortoise Management\
To:                  C:\xampp\htdocs\tortoise_management\

Files to copy:
  • db_connect.php
  • header.php
  • index.php
  • create.php
  • edit.php
  • delete.php
  • feeding_logs.php
  • health_records.php
  • breeding_records.php
  • tasks.php
  • alerts.php
  • database/fullDatabase.sql
  • All .md and .txt documentation files


STEP 3: Start XAMPP Services
──────────────────────────────
1. Open XAMPP Control Panel
2. Click "Start" next to Apache
3. Click "Start" next to MySQL
(Both should show green ✅ indicators)


STEP 4: Import Database
────────────────────────
1. Open in browser: http://localhost/phpmyadmin
2. Click "Import" tab
3. Click "Choose File"
4. Select: database/fullDatabase.sql
5. Click "Import"
6. Wait for success message ✅


STEP 5: Launch Application
────────────────────────────
Open in browser: http://localhost/tortoise_management/

You should see:
  ✅ Tortoise Conservation Dashboard
  ✅ Green header bar with navigation
  ✅ Table showing 5 sample tortoises
  ✅ Edit and Delete buttons

❓ COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

❌ "Can't connect to database"
✅ Solution: Verify MySQL is running in XAMPP Control Panel

❌ "Access denied for user 'root'"
✅ Solution: Check db_connect.php has empty password: $db_pass = '';

❌ "Page won't load"
✅ Solution: Verify Apache is running and files are in C:\xampp\htdocs\

❌ "No tables in database"
✅ Solution: Go to http://localhost/phpmyadmin and re-import SQL file

❌ See blank page with no errors
✅ Solution: Press F12 → Console tab → Check for error messages

📊 PAGE GUIDE
═══════════════════════════════════════════════════════════════════════════════

Dashboard (index.php)
  └─ Main page showing all tortoises

  └─ Query: SELECT with JOINs

Register (create.php)
  └─ Form to add new or edit existing tortoise
  └─ Fields: Species, Gender, Weight, Entry Date, Origin, Enclosure, Status
  └─ Operations: INSERT or UPDATE

Feeding Logs (feeding_logs.php)
  └─ View all feeding records
  └─ Columns: ID, Tortoise, Species, Food, Amount, Caretaker, Time

Health Records (health_records.php)
  └─ View medical history
  └─ Shows: Diagnosis, Treatment, Vaccination dates, Vet

Breeding Records (breeding_records.php)
  └─ View breeding program data
  └─ Shows: Male/Female pairs, Success rates, Egg counts

Tasks (tasks.php)
  └─ View staff task assignments
  └─ Shows: Description, Due date, Status, Assigned to

Alerts (alerts.php)
  └─ View environmental alerts from IoT sensors
  └─ Shows: Trigger reason, Status, Resolved by, Timestamp
